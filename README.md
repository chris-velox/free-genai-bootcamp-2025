# free-genai-bootcamp-2025

Repository for ExamPro Free GenAI Bootcamp 2025

## Project Structure

This repository contains several sub-projects related to German language learning and AI:

### Main Projects

- `lang-portal/` - Updated version of the Language Portal from the class
- `reiseabenteuer/` - Final assignment project
- `language-learning-assistant/` - Du'an's Amazon Bedrock and RAG project implementation

### Design & Architecture

- `genai-architecting/` - Preliminary design documentation for the German language portal. Go to the [Readme.md](genai-architecting/Readme.md) in that folder for an index to the content.
- `fast-portal/` - Technical specifications for an earlier German language portal concept (archived)

### Experimental & Learning Projects

- `implementing_ML/` - Jupyter notebook for machine learning experimentation
- `agent/` - Sub-project related to AI agent development
- `sentence-constructor/` - Collection of prompts for various LLMs (ChatGPT, Claude, etc.) for German sentence construction assistance
- `opea-comps/` - OPEA implementation attempt

### Development

- `plans/` - Implementation plans for study sessions feature in lang-portal
